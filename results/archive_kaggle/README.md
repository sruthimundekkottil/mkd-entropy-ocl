# Archived Kaggle runs

These folders hold experiments run in Kaggle notebooks in May 2026, kept for the record only. They ran on copies of the VR-OCL code pasted into the notebooks, and those copies were edited between runs, so **the code version behind each folder cannot be confirmed** from the files. With the same seeds and settings, they also gave a different ER baseline from the local runs. They are therefore excluded from all headline tables and figures. `archive_tables.md` (generated by `scripts/make_report_tables.py`) summarises the folders marked `archive` in `results/manifest.csv`, for traceability of the numbers quoted in `docs/report_errata.md`. Folders under `invalid/` and `duplicates/` are not used at all; `results/PROVENANCE.md` explains why.
